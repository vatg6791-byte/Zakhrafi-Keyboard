# Zakhrafi Keyboard

لوحة مفاتيح iOS متخصصة في الرموز والزخارف النصية المفيدة للتصميم.

## الأقسام
- إطارات وزوايا
- حدود وخطوط وفواصل
- أقواس وعلامات اقتباس مزخرفة
- أشكال هندسية
- أسهم واتجاهات
- رموز تقنية وواجهات
- رموز كتابية وزخارف مستقلة

## الخصائص المستهدفة
- بحث داخل الرموز
- نسخ وإدراج مباشر من لوحة المفاتيح
- مفضلة وأقسام منظمة
- تصميم داكن وألوان قابلة للتطوير
- عمل محلي دون اتصال بالإنترنت

## التقنية
Swift وUIKit وامتداد لوحة مفاتيح مخصص لنظام iOS.

> المشروع قيد التطوير. يحتاج إلى البناء والتوقيع المتوافقين مع iOS قبل التثبيت.
